Kanton Bern UI Component Library

Welcome to the Kanton Bern UI Component Library sample application. This library provides a comprehensive set of Angular components styled according to the Kanton Bern design system.

Installation & Requirements

Install with npm:

npm install @nexplore/practices-ui-ktbe

Requirements:

  • Angular 22
  • Tailwind CSS 4.x
