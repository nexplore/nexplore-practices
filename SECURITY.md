# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities by email to **security@nexplore.ch**.

Do not open a public GitHub issue, pull request or discussion for a vulnerability.

Please include:

- the affected package(s) and version(s) (`Nexplore.Practices.*` NuGet packages or `@nexplore/practices-*` npm packages)
- a description of the issue and its impact
- steps or a minimal reproducer
- a suggested fix, if you have one

We will confirm that we received your report, investigate it and keep you informed about the fix. Please give us
reasonable time to release a fix before you disclose the issue publicly.

## Supported versions

Security fixes are released for the latest minor version of the current major version (currently `11.x`).
